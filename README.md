# NOCTA — сайт премиального маркетингового агентства

Концепт-сайт (портфолио-работа): одностраничный лендинг вымышленного агентства NOCTA в фиолетово-неоновой стилистике. Glassmorphism, неоновое свечение, анимации. Все бренды, люди, цифры и награды выдуманы.

## Стек
Чистые HTML, CSS и JavaScript. Сборка не нужна, зависимостей нет. Шрифты подключаются из Google Fonts: Unbounded, Manrope и Playfair Display (все с кириллицей).

```
agency-site/
├── index.html   — разметка, 9 секций + футер
├── styles.css   — стили, адаптив, анимации
├── script.js    — интерактив (reveal, счётчики, меню, форма и т. д.)
└── shots/       — скриншоты для превью
```

## Секции
1. Hero: стеклянная навигация, крупный заголовок, анимированная неоновая сфера, цифры и бегущая строка клиентов.
2. Услуги: 6 стеклянных карточек с наклоном и подсветкой под курсором.
3. Подход: таймлайн из 5 этапов, линия прорисовывается при прокрутке.
4. Кейсы: 4 кейса с абстрактными SVG-обложками и метриками.
5. Экспертиза: анимированные счётчики, шкалы компетенций, награды.
6. Команда: 6 человек, аватары-инициалы в светящихся рамках.
7. Отзывы.
8. FAQ: аккордеон.
9. CTA и форма заявки (только фронтенд, с экраном успешной отправки), футер.

## Как открыть
Просто откройте `index.html` в браузере. Для локального сервера:

```bash
cd agency-site
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Деплой

### GitHub Pages
1. Создайте репозиторий и загрузите в корень файлы `index.html`, `styles.css`, `script.js`.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

### Netlify
- Самый быстрый вариант: откройте https://app.netlify.com/drop и перетащите папку `agency-site`.
- Или подключите GitHub-репозиторий: Build command оставьте пустым, Publish directory: `/`.

### Vercel
`npx vercel` в папке проекта, фреймворк: «Other».

## Как подключить форму
Сейчас форма только показывает экран «Заявка принята». Чтобы заявки приходили на самом деле:
- **Netlify Forms:** добавьте тегу `<form>` атрибуты `name="contact" data-netlify="true"` и уберите `e.preventDefault()` в `script.js`.
- **Telegram:** отправляйте `fetch` на свой бэкенд или бота, который пересылает заявку в Telegram. Токен бота нельзя хранить во фронтенде.

## Доступность и производительность
- Семантичная разметка, skip-link, видимый фокус, `aria`-атрибуты у меню, аккордеона и формы.
- Если в системе включено «уменьшение движения» (`prefers-reduced-motion`), анимации отключаются.
- Курсорное свечение, магнитные кнопки и наклон карточек работают только на устройствах с мышью.
- Без картинок и библиотек: вся графика сделана на CSS и SVG.
